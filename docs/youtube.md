## Title
Admin Toolkit for Salesforce — full walkthrough: flows, data deployment, field cleanup, logs

## Description (paste as is)
A Chrome extension for Salesforce admins that works through the org tabs you already have open — no separate login, no server in between. Anything that changes something in Salesforce shows what it is about to do and asks first; where a tool can read the org back afterwards it says "verified".

Open source (Apache 2.0): https://github.com/YonatanAshkenazi53/salesforce-toolkit
Privacy: everything stays on your PC. No analytics, no account, no server.
